# **App Name**: Zenith Timer

## Core Features:

- Timer Setting: Set a meditation duration using a timer with customizable time increments.
- Sound Selection: Play a selection of ambient sounds (e.g., nature sounds, binaural beats) during the meditation session.
- Visual Aid: Display a calming visual, such as a slowly changing color gradient or a simple animation.
- Start/End Gong: Gong sound plays at the start and end of the meditation session.
- Customizable Chimes: Play customizable chime sound at set intervals (e.g., every 2, 5, or 10 minutes).
- Streak Tracking and Heat Map: Record meditation streak and display a heat map of meditation activity.
- Japa Counter: Include a Japa counter on the main timer page; tapping anywhere on the page increments the count.

## Style Guidelines:

- Primary color: Soothing blue (#A7D1AB) to promote calmness.
- Secondary color: Light gray (#F0F0F0) for backgrounds and neutral elements.
- Accent: Teal (#2E8B57) for interactive elements and highlights.
- Clean and minimalist design with plenty of whitespace.
- Simple, line-based icons for navigation and settings.
- Subtle fade-in/out animations for transitions and visual aids.
